# cit331-assignment1-F24-BSCS-0030/
A multi-page website for a fictional or real university club.
This is built for the CIT331 Web Technology Assignment : 1. This show the upcoming club events and allow students to register using form taht saves data to the browser's local storage.

## Pages
  Home ('index.html') club introduction, features events, and contact information.

  Events ('events.htm') A list of free and popular events.

  Register ('register.html) A registration form with localstorage saving and a table to display saved registration.
